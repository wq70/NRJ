# 内置聊天表情

用户在单聊或群聊点击原来的表情按钮，即可选择平台分类并直接发送。分类栏可以横向滑动；放大镜可以搜索名称或平台，“最近”保留最近使用的 24 个内置表情。

原有个人表情位于“我的”，导入、分组、角色专属、全局和群专属表情仍使用原来的管理入口和存储。

角色设置新增“允许使用内置表情”开关，默认关闭。打开后角色根据表情名称选择发送，无需导入图片。群成员设置中的同名开关可独立控制该成员在群中的使用权限。这个开关不改变原有表情的权限，也不强制角色每轮发送表情。

每个表情显示上游提供的简短名称，如“微笑”“哈哈”；名称用于搜索和角色理解，并非自动生成的长篇图片描述。平台同名表情通过平台名称和资源 ID 区分。

内置资源共 2340 个，分为微信、QQ、抖音、B站、小电视、微博、小红书、贴吧、钉钉、酷安、闲鱼、IT之家、淘宝、携程、米游社 15 个分类。图片随应用打包，不在打开面板时访问上游图库；QQ 保留可用的 APNG 动画，米游社收录默认米游兔。图片会增加约 70 MB 的发布体积。

识图仍遵循原来的图像开关。发送给远程视觉模型前，只将实际聊天中选中的内置图片转换为静态 PNG 数据，不会为了角色选择表情上传整套图库。内置图片不写入个人表情数据库，备份只保存消息 ID 和最近使用记录；移动应用打包后可直接使用，网页离线可用性取决于原有缓存能力。

资源清单：`src/constants/builtInChatEmojis.json`。图片及来源声明：`public/chat-emojis/`。更新资源：`node scripts/sync-built-in-chat-emojis.mjs`。专项验证：`npx tsx scripts/test-built-in-chat-emojis.ts`。

上游仓库和素材使用声明见 `public/chat-emojis/SOURCES.md`。
