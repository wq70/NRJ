# 弹幕与虚拟观众

聊天、群聊、线下见面、游戏房间、文游游玩页、直播现场和共赏内容页都有紧凑的“观众席”入口。高级设置 → 弹幕与观众可以管理全局默认、各场景默认、观众和历史记录。聊天设置 → 衍生也能打开当前聊天的观众设置。

## 开启与生成

功能默认关闭，生成默认手动。进入观众席后开启模式，再选择生成方式：

- 手动：点击“生成弹幕”。相同公开内容优先读取缓存。“重写本段”保留收藏、置顶和用户评论，替换其他本段评论。
- 自动：跟随完整公开事件。聊天只在成功完成整轮回复后触发；停止、失败或切换候选不会被当成新的完成信号。
- 本地气氛短句：不调用模型，只提供轮换的简单现场反应，不具备内容理解能力。

API 设置的“弹幕生成”能力可以分配到已有节点或独立节点。未绑定时沿用项目现有的默认节点规则。请求失败不自动换节点，也不阻塞聊天、游戏或文游。每次请求生成多位虚拟观众的评论；模型只收到当前场景允许观看的内容。

调用间隔、每隔多少个事件生成、每场调用限额和公开正文预算均可调。已经发出的请求即使取消或失败，也计入次数。本地短句不计入模型调用次数。隐藏弹幕、暂停动画、停止自动生成和关闭观众模式分别有独立操作。

## 显示与互动

支持静态评论条、滚动弹幕和仅观众席列表。字体、颜色、透明度、昵称、速度、同屏条数和减少动态效果可以调整。编辑输入、阅读旧消息、选择文字、打开观众席及原功能弹窗时会暂停动画。弹幕层不截获正文点击。

围观模式不会让角色知道评论。分享模式由用户选中评论后给角色看。节目模式也是显式选中评论，请角色在节目现场回应，不循环自动追问。游戏可以选择具体回应者，回应不会推进题目、回合或改变积分。文游及没有陪伴角色的共赏只支持围观。

虚拟站队按已生成的投票评论计数，每个观众在同一事件只计最近的一票，不代表真人数量，也不改变游戏结果。预测在观众席由用户标注猜中或未猜中，可撤销标注。

## 观众与记录

内置磕 CP、搞笑、分析、温柔、怀疑和路人观众。可编辑昵称、性格、口吻、代表色和活跃度；可添加、删除或屏蔽观众，选择固定名单或按活跃度随机阵容。气氛预设配合自定义要求可表达混合风格。观众接梗只参考本分支允许观看的记录，不读取角色心声或其他账号数据。

评论可以收藏、置顶、屏蔽类型和导出名场面文字，导出时可选择包含原文。历史记录支持展开和分页。清理及自动过期保留收藏、置顶。各账号独立存入 `nrt-danmaku/danmakuState`；可通过现有数据备份与恢复迁移，通过存储管理查看占用。

聊天撤回、删除或编辑后，来源不再匹配的评论从当前现场隐藏，历史档案仍可在管理页面查看。回复候选与时间线切换显示匹配的评论。文游回退和读档只显示当前走过的路径；观众不知道未到达节点或隐藏结局。游戏观众不读取卧底身份、隐藏词语或底牌。

共赏观众只收到允许分享的可见阅读片段和本场公开聊天。没有提供字幕、正文或画面时，不会假装理解影片；可在共赏聊天中描述内容。该功能不自动启动摄像头、录音、识图或字幕提取。

## 验证

`npm run test:danmaku` 使用独立内存账号、模拟 API 和系统临时目录测试公开上下文过滤、分支与读档、连续生成、限额、缓存、取消、账号隔离和完成信号，不读写真实聊天数据，不启动服务。
