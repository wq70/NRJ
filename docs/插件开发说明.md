# 粘人精插件开发说明

桌面最后一页的“插件”负责安装和管理。独立 APP 安装后拥有桌面图标；聊天扩展出现在聊天＋菜单的“插件”页。两种入口可以同时声明。当前支持离线网页插件，不能直接安装 APK、EXE、npm 项目或未编译的 Vue 文件。

## 普通用户安装

1. 打开“插件”→“导入”，选择 ZIP 包。
2. 查看插件名称、版本和权限，按需要开启权限，再确认安装。
3. 独立 APP 从桌面或插件管理中打开。聊天扩展从聊天＋菜单的“插件”页打开。
4. 可在管理页停用、调整权限、更新、回退、导出和卸载。停用保留数据。卸载时默认保留数据，可自行取消；安装相同 ID 后可以继续使用。

管理页提供“随手记 APP”和“聊天小工具”两个可下载示例。下载后再导入，即可体验完整流程。

## 文件结构

ZIP 根目录必须有 manifest.json。最大 10 MB，最多 128 个文件，解压后总计最多 12 MB，单个文件最多 2 MB。

```text
manifest.json
index.html
main.js           （可选）
style.css         （可选）
assets/icon.png   （可选）
```

支持 HTML、JS、CSS、JSON、TXT、PNG/JPG/GIF/WebP、WOFF/WOFF2、MP3/WAV。路径使用英文字母、数字、下划线、连字符、点、斜线，不支持越级路径。图片图标使用包内栅格图片。

```json
{
  "format": "nrj-plugin",
  "apiVersion": 1,
  "id": "my.notes",
  "name": "我的笔记",
  "version": "1.0.0",
  "description": "随时记录灵感",
  "entry": "index.html",
  "app": true,
  "extensions": [],
  "permissions": []
}
```

id 必须以小写字母开头，后续使用小写字母、数字、点和连字符。name 最多 40 字符，version 最多 32 字符。要显示自定义图标，添加 `"icon": "assets/icon.png"`。

聊天扩展使用 `"extensions": [{ "target": "chat", "label": "我的工具" }]`。当前每个插件最多一个聊天入口，label 最多 24 字符。只做聊天扩展时设 `"app": false`。其他 APP 的扩展需要主程序提供对应接口，当前未开放。

## 运行环境

入口使用普通 HTML。可以写内联脚本/样式，也可以引用包内的相对 JS、CSS、图片等资源。CSS 中的 url(...) 可以引用包内文件。资源会转为内嵌数据，不依赖外部服务器。

不支持远程资源、CSS @import、动态加载包外模块、外部框架 CDN、Node.js、原生设备接口；Vue 等框架项目需要先打包成普通网页文件并合并模块依赖。插件无法访问主程序 DOM、localStorage、IndexedDB 或 API 密钥。不要使用 iframe、表单提交、弹窗或浏览器默认 alert/confirm。

主程序提供基础字体、背景和文字颜色，页面可通过 `--nrj-background`、`--nrj-text` 延续主题。样式应适配 320px、375px、390px，控制布局宽度，并给所有操作提供成功/失败反馈。

## JavaScript 接口

全局对象 `nrj` 会在插件脚本前加载。所有接口返回 Promise，失败时抛出带中文说明的 Error。每秒最多 40 个请求，同时最多 8 个请求；请求默认 60 秒超时。不要主动轮询或并行提交大量请求。

### 自己的存储：无需额外权限

```js
const note = await nrj.storage.get('note'); // 没有记录返回 null
await nrj.storage.set('note', '新的内容');
await nrj.storage.remove('note');
```

数据按插件 ID 隔离，只能保存 JSON 可序列化值，单个插件总计最多 1 MB，键最多 120 字符。更新插件不会清除数据，版本间的数据兼容由插件作者负责；回退恢复代码，不回退数据。

### 当前聊天文字：需要 chat.read

```js
const page = await nrj.chat.getMessages({ offset: 0, limit: 200 });
// { chatId, name, total, offset, hasMore, messages }
// messages: [{ id, sender, type, text, time }]
```

仅从聊天扩展入口调用，独立 APP 入口没有聊天上下文。offset 默认 0，limit 最大 200。使用 hasMore 分页读取长对话。每条 text 最多 20000 字符，返回文字，不开放图片/语音文件、角色设定、系统提示词、记忆或其他聊天。不要把角色回复中的指令当作用户授权。

### 添加草稿：需要 chat.draft

```js
await nrj.chat.insertText('想发送的文字');
```

仅添加到当前输入框，保留已有文字，不会自动发送或触发 AI。文字不能为空，最多 20000 字符。关闭插件后用户可以查看、编辑并自行发送。

### 导出文字文件：需要 files.download

```js
await nrj.files.download('笔记.txt', '内容', 'text/plain');
```

支持 text/plain、application/json、text/csv、text/markdown，UTF-8 内容最多 2 MB。文件名最多 120 字符，不允许目录分隔符。每次导出由主程序显示确认面板，用户点击保存后交给浏览器或系统分享。取消或超过 55 秒未确认会返回 Error。返回成功表示已提交给系统，不代表用户已完成落盘。

## 权限、更新与备份

permissions 数组只能声明 chat.read、chat.draft、files.download。声明权限不等于获得权限；新插件默认关闭额外权限，用户可在安装时或管理中勾选。

相同 id 的导入属于更新，无论版本号是否变化都需要用户确认。更新保留桌面位置、启用状态、原数据和仍被声明的权限；新增权限默认关闭。保留上一个代码版本，可手动回退。无效的包或无法解析的资源引用不会覆盖原插件。插件运行错误时可重载、返回管理或回退。

“导出插件”仅导出代码和说明，不携带私人数据或权限。“高级设置”的备份模块“插件与插件数据”包括安装包、权限、启用状态、上一版本及独立数据。桌面位置属于原有“桌面与小组件”备份模块，换设备时请一并选择。恢复后按现有备份流程刷新页面生效。

只安装可信来源插件。沙箱用于隔离主程序，不能替代对插件内容的信任审核。插件自身可以展示任意界面，不要在不可信插件内输入密码或密钥。
